# Práctica de Control de Versiones con Git y GitHub

## 📖 Descripción del Proyecto

Este repositorio contiene el desarrollo y las evidencias prácticas de los ejercicios de control de versiones con **Git** y la plataforma colaborativa **GitHub**. El objetivo principal es afianzar el flujo de trabajo estándar en entornos de desarrollo de software, abarcando desde la gestión de archivos y ramas hasta la automatización del ciclo de vida y documentación.

## 🎯 Contenidos y Objetivos

A continuación se resumen los módulos desarrollados a lo largo de la práctica:

* **Gestión de Versiones y Distribución:** Creación de archivos de seguimiento, publicación de *Releases* con etiquetado semántico y administración de incidencias mediante *Issues*.
* **Trabajo Temporal:** Uso eficiente de `git stash` para almacenar modificaciones en curso y permitir cambios ágiles de contexto.
* **Documentación Técnica:** Maquetación estructurada del proyecto mediante marcado **Markdown** (`README.md`).
* **Reglas de Exclusión:** Configuración de `.gitignore` para omitir dependencias, variables de entorno y archivos residuales del sistema.
* **Integración de Ramas:** Comparativa y aplicación práctica de estrategias de fusión (*Fast-Forward* vs. *No Fast-Forward*).
